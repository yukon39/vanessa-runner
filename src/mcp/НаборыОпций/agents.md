# Наборы опций MCP

Руководство по созданию и актуализации MCP-инструментов, зеркалирующих CLI-наборы опций.

## Связанные файлы

```
src/cli/НаборыОпций/НаборОпций*.os   — источник истины (определения &Опция)
src/mcp/КонтекстВанессаMCP.os      — хранит экземпляры наборов на время сессии
src/mcp/НаборыОпций/
  agents.md                          — эта инструкция
  Инструмент*Options.os              — MCP-инструменты наборов опций
```

Каждый файл `Инструмент*Options.os` в этой папке — один MCP-tool для одного CLI-класса `НаборОпций*`.

## Реестр

| CLI-класс | MCP tool | Файл | Параметры |
|-----------|----------|------|-----------|
| `НаборОпцийПодключения` | `connection-options` | `ИнструментConnectionOptions.os` | `ibconnection`, `db-user`, `db-pwd`, `ibcmd` |
| `НаборОпцийПлатформы` | `platform-options` | `ИнструментPlatformOptions.os` | `v8version`, `uccode`, `language`, `locale` |
| `НаборОпцийСУБД` | `dbms-options` | `ИнструментDbmsOptions.os` | `dbms-type`, `dbms-server`, `dbms-base`, `dbms-user`, `dbms-pwd` |
| `НаборОпцийХранилища` | `storage-options` | `ИнструментStorageOptions.os` | `storage-name`, `storage-user`, `storage-pwd`, `storage-ver` |
| `НаборОпцийКластера` | `cluster-options` | `ИнструментClusterOptions.os` | `ras`, `rac`, `db-name`, `cluster`, `cluster-name` |
| `НаборОпцийЗапуска` | `run-options` | `ИнструментRunOptions.os` | `nocacheuse`, `ordinaryapp`, `additional`, `ibsrv`, `ibsrv-direct`, `ibsrv-debug` |
| `НаборОпцийАдминистрирования` | `admin-options` | `ИнструментAdminOptions.os` | `cluster-admin`, `cluster-pwd` |
| `НаборОпцийОбновленияБД` | `update-db-options` | `ИнструментUpdateDbOptions.os` | `rtype`, `dynamic` |
| `НаборОпцийНастроек` | `settings-options` | `ИнструментSettingsOptions.os` | `settings` |
| `НаборОпцийIbcmd` | `ibcmd-options` | `ИнструментIbcmdOptions.os` | `ibcmd` |

Именование:

- MCP tool: `{группа}-options` (kebab-case / dash-style)
- Параметры tool: **как в CLI** — те же `Имя` из `&Опция` (обычно тоже kebab-case)
- Файл: `Инструмент{Группа}Options.os` (PascalCase)
- Описание tool: `Установить опции {назначение набора}`

> **Правило:** kebab-case (dash-style) для имён tools и параметров — как в CLI. Не использовать snake_case и underscore.

## Соответствие CLI → MCP

Параметры копируют `&Опция` из CLI **с теми же `Имя` и `Описание`**:

| CLI | MCP |
|-----|-----|
| `&Опция(Имя, Описание)` | `&ПараметрИнструмента(Имя, Описание)` |
| `&ТСтрока` | `string` (тип по умолчанию) |
| `&Флаговый` | `Тип = "boolean"` |
| `&ТПеречисление` | `Тип = "string"`, к описанию дописать допустимые значения |

Для перечислений расширяйте описание, не заменяя исходный текст:

```bsl
// CLI:  Описание = "Тип СУБД"
// MCP:  Описание = "Тип СУБД. Значения: MSSQLServer, PostgreSQL, IBMDB2, OracleDatabase"
```

Имя переменной в инструменте совпадает с полем CLI-набора (`СтрокаПодключения`, не `ibconnection`).

## Структура инструмента

Эталон — `ИнструментConnectionOptions.os`.

```bsl
// BSLLS:MissingVariablesDescription-off Поля &ПараметрИнструмента - описания заданы в аннотациях.

&Пластилин("КонтекстВанессаMCP")
Перем КонтекстMCP;

&ПараметрИнструмента(Имя = "ibconnection", Описание = "Строка подключения к информационной базе (/F или /S)")
Перем СтрокаПодключения;

&Инструмент(Имя = "connection-options", Описание = "Установить опции подключения к информационной базе")
Процедура ПриСозданииОбъекта()
КонецПроцедуры

&ВыполнениеИнструмента
Функция ВыполнениеИнструмента() Экспорт
    // см. «Логика выполнения»
КонецФункции
```

## Логика выполнения

### 1. Частичное обновление

```bsl
НаборОпций = КонтекстMCP.НаборОпцийПодключения();

Если СтрокаПодключения <> Неопределено Тогда
    НаборОпций.СтрокаПодключения = СтрокаПодключения;
КонецЕсли;
```

Обновляются только переданные параметры.

### 2. Ответ

```bsl
Ответ = Новый Соответствие;
Если НаборОпций.СтрокаПодключения <> Неопределено Тогда
    Ответ.Вставить("ibconnection", НаборОпций.СтрокаПодключения);
КонецЕсли;
Возврат Ответ;
```

Ключи ответа — `Имя` из `&Опция` CLI, не имена переменных.

### 3. Маскировка учётных данных

| Маскировать | Примеры имён |
|-------------|--------------|
| Пароли | `*-pwd` |
| Пользователи | `db-user`, `dbms-user`, `storage-user`, `cluster-admin` |

Значение в ответе: `"********"`.

## КонтекстВанессаMCP

Файл `src/mcp/КонтекстВанессаMCP.os` — по одному экземпляру каждого CLI-набора на сессию.

```bsl
#Использовать "../cli"

Перем НаборОпцийПодключения;
// ... все Перем в начале файла ...

Функция НаборОпцийПодключения() Экспорт
    Возврат НаборОпцийПодключения;
КонецФункции

&Желудь
Процедура ПриСозданииОбъекта()
    НаборОпцийПодключения = Новый НаборОпцийПодключения();
КонецПроцедуры
```

На каждый новый CLI-набор: `Перем` + геттер + `Новый ...()` в `ПриСозданииОбъекта`.

## Создание

Когда в `src/cli/НаборыОпций/` появился новый `НаборОпций*`:

1. Добавить набор в `КонтекстВанессаMCP.os`.
2. Создать `Инструмент{Группа}Options.os` по эталону.
3. Скопировать все `&Опция` → `&ПараметрИнструмента`.
4. Реализовать три блока логики (обновление, ответ, маскировка).
5. Добавить строку в реестр этого файла.

## Актуализация

При изменении `src/cli/НаборыОпций/НаборОпций*.os`:

| Изменение в CLI | Действие |
|-----------------|----------|
| Добавлена `&Опция` | Параметр, присвоение, ключ ответа |
| Изменены `Имя` / `Описание` | Синхронизировать в инструменте |
| Изменён тип опции | Обновить `Тип` в `&ПараметрИнструмента` |
| Добавлены значения перечисления | Дополнить `Описание` |
| Удалена `&Опция` | Удалить из инструмента |
| Переименован CLI-класс | Обновить контекст и ссылку в инструменте |

Чеклист:

- [ ] `&ПараметрИнструмента` = `&Опция` по количеству
- [ ] Имена и описания совпадают с CLI
- [ ] Имена переменных совпадают с полями CLI-набора
- [ ] Каждый параметр — блок `Если ... <> Неопределено`
- [ ] Каждое поле — ключ в ответе
- [ ] Учётные данные маскируются
- [ ] Реестр обновлён
